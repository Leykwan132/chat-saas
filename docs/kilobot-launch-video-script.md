## Delivery notes

- Pause after “let me show you” before the WhatsApp cut.
- Slightly slower on the WhatsApp hook and the booking payoff.
- On Agent Setup, say the Ilmu + free line as one breath — don’t rush “sovereign.”
- On CTA, stress the difference: **starts free for everyone** → **early adopters get 3 months free**.
- On the montage: let the screen carry it — say the line once, don’t name every flash.
- One breath between sections so it doesn’t sound like a feature list.

---

## What changed in this refine

| Issue | Fix |
|-------|-----|
| Intro listed knowledge / model / workflow, then the demo repeated them | Intro now sells the outcome only; demo shows the how |
| Free + Ilmu + tone felt like three separate pitches | Combined Ilmu + free into one line; tone/test into one closer |
| “Starts free” and “3 months free” could sound like the same offer | CTA now sequences them: free for everyone, *and* early adopters get 3 months |
| “Next —” felt tutorial-y | Softened to “Then…” |
| 60s cut was one long run-on | Split into short spoken beats |
| End card stacked too many free claims | Cleared hierarchy: starts free / Ilmu / early adopter 3 months |

# Docs Callouts and Balanced Layout Design

## Goal

Give every documentation callout the borderless visual language in the supplied reference and balance the desktop article between the left navigation and the right page outline.

## Callout system

All Docusaurus admonitions share one structure:

- No border or shadow.
- A softly tinted semantic background.
- A `0.875rem` radius.
- `1.5rem 2rem` desktop padding and `1.25rem` mobile padding.
- A colored icon and title.
- Normal foreground text for the body.
- Consistent title, body, and paragraph spacing.

Semantic variants remain recognizable:

- Note and Info use teal.
- Tip uses green.
- Warning and Caution use amber.
- Danger uses red.

The treatment must work in light and dark themes. The background mixes 10% of the semantic color into the normal light surface and 18% into the normal dark surface. Existing admonition Markdown and icons remain unchanged.

## Desktop layout

At the `997px` desktop breakpoint, the docs content row uses:

```css
grid-template-columns:
  minmax(2.5rem, 1fr)
  minmax(0, 56rem)
  minmax(2.5rem, 1fr)
  clamp(14rem, 18vw, 19rem);
```

The four tracks are:

1. A flexible spacer between the left sidebar and article.
2. The centered article, capped at a readable maximum width.
3. A second flexible spacer equal to the first.
4. A dedicated right page-outline rail.

The two spacer tracks use the same sizing rule, so the article receives matching visual breathing room on both sides. The right outline rail ends at the right edge of the docs area rather than floating directly beside the article.

The article remains fluid when the viewport cannot fit its preferred maximum width. The page outline keeps its existing sticky vertical behavior.

Below the desktop breakpoint:

- The four-track grid is not applied.
- The desktop outline remains absent.
- The existing mobile outline and article padding remain unchanged.
- No horizontal overflow is introduced.

## Implementation boundaries

Use the existing `DocRoot/Layout/Main` CSS module and table-of-contents CSS. Do not copy or fork Docusaurus layout components unless the existing stable row and column hooks cannot express the layout.

Keep the callout styles in the global docs CSS because admonitions are generated by Docusaurus. Do not create a custom React callout component or change guide content solely to exercise the styling.

## Verification

Add focused source contracts that require:

- Borderless shared admonition styling.
- Semantic Note/Info, Tip, Warning/Caution, and Danger variants.
- Light and dark theme-aware surfaces.
- Equal flexible spacer tracks around the article.
- A dedicated far-right outline track.
- Desktop-only application of the grid.

Run the docs test suite, rendered component tests, TypeScript, production build, and whitespace checks. Visually verify:

- A published warning callout in light and dark themes.
- A wide desktop page with the article centered between equal spacer tracks.
- The right outline mounted to the far-right rail.
- A 390px mobile page with no horizontal overflow.

# Roles and permissions

<DocVerified date="2026-07-28" />

Roles control what each teammate can see and manage in the workspace. KiloBot starts with three roles.

<DocOutcomes>

### By the end, you will

- Understand Owner, Admin, and Member
- Know that only the Owner controls role access
- Give each teammate the access they need

</DocOutcomes>

## Three roles

| Role | What it means |
| --- | --- |
| **Owner** | Owns the workspace and controls what each role can see and manage. |
| **Admin** | Helps run the workspace with the access set by the Owner. |
| **Member** | Works with the access set by the Owner. |

:::important
Only the **Owner** can set what each role can see and manage. Admins and Members use the access the Owner gives them.
:::

## Give access

1. Open **Settings → Teams**.
2. Select a teammate and choose **Admin** or **Member**.
3. As the Owner, choose what that role can see and manage, then save.

# Workspace and team

## Overview

The workspace is where owners and permitted administrators manage people, agents, invitations, settings, and usage. Use it for organization-level access and billing context; configure each agent's customer experience inside the agent. Related guides: [Roles and permissions](/team/roles-and-permissions) and [Lead Assignment](/team/lead-assignment).

## Invite a teammate

Send an invitation with the smallest role that covers the work the person will do.

<ol className="steps">
  <li>Open <strong>Invitations</strong> from the workspace sidebar, or <strong>Settings → Teams</strong> to manage members and roles.</li>
  <li>Enter the teammate's email.</li>
  <li>Choose the appropriate role.</li>
  <li>Send the invitation.</li>
</ol>

The recipient must accept before they become an active member. If an invitation is pending, verify the email before sending another.

## Manage members

Review membership regularly so access matches current responsibility.

<ol className="steps">
  <li>Review active members and their roles.</li>
  <li>Confirm each person has access to the work they should own.</li>
  <li>Use the smallest role that allows the teammate to do their job.</li>
  <li>Update or remove access when responsibility changes.</li>
</ol>

A member may need **Inbox** access without permission to change **Agent Setup**, **Workflow**, billing, or team administration.

## Work across agents

Each agent is a separate customer experience inside the same workspace.

<ol className="steps">
  <li>Open the workspace agent list to see agents available to the user.</li>
  <li>Inside an agent dashboard, use the agent switcher in the header to move to another agent.</li>
</ol>

## Settings and usage

Organization-level controls and consumption live outside individual agent dashboards.

<ol className="steps">
  <li>Open <strong>Settings</strong> for organization-level controls.</li>
  <li>Open <strong>Usage</strong> to review plan, credits, limits, and related activity.</li>
</ol>

Check **Usage** before inviting many teammates, creating agents, or connecting channels.

:::note
If a teammate cannot see an agent or feature, confirm membership and role permissions first — see [Troubleshooting](/help/troubleshooting).
:::

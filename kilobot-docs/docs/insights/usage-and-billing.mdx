# Usage and billing

KiloBot plans combine workspace limits, monthly credits, model access, feature access, and Knowledge Base storage.

**Usage** is the source of truth for the active subscription and current consumption.

## Monitor credits

AI activity consumes credits according to the model and work performed. Credit periods reset according to the active subscription schedule.

If credits run out, AI-dependent activity may stop even though teammates can still use permitted tools.

<ol className="steps">
  <li>Open <strong>Usage</strong> to review the workspace credit meter and plan context.</li>
  <li>Monitor consumption after connecting a high-volume channel, enabling automatic replies, or expanding a <strong>Workflow</strong>.</li>
</ol>

## Understand plan allowances

Plans can differ in:

- Monthly credits
- Number of team members
- Number of agents and connected channels
- **Knowledge Base** storage per agent
- Available AI models
- **Broadcast**, **Follow-up**, auto-reply, customization, and **Analytics** features

Check Pricing and **Usage** before relying on a feature or limit in a rollout plan.

## Manage Knowledge Base storage

Storage is tracked per agent. Review usage before upgrading only for storage headroom.

<ol className="steps">
  <li>Open <strong>Knowledge Base</strong> for the agent.</li>
  <li>Review the <strong>Storage limit</strong> panel for usage by source type and total allowance.</li>
  <li>Delete obsolete files and duplicated sources before upgrading only for storage.</li>
</ol>

## Separate KiloBot credits from WhatsApp charges

WhatsApp Message Template costs for **Broadcasts**, **Reminders**, and **Follow-ups** are billed directly by Meta, not through KiloBot.

KiloBot may show estimated MYR costs based on the saved template category, but Meta's bill and pricing rules are authoritative.

:::note
KiloBot credits and Meta WhatsApp charges are separate. A workspace can have available KiloBot credits and still incur provider charges for template messages.
:::

If usage does not match the activity shown in your workspace, see [Contact support](/help/contact-support).

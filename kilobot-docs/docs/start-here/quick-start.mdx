# Quick Start

<DocVerified date="2026-07-30" />

In about 5 minutes, you will create and test a working agent using Northstar Dental as the example.

<DocOutcomes>

### By the end, you will

- Create a working agent
- Add one trusted answer
- Test that the agent uses the approved answer

</DocOutcomes>

## 1. Create your agent

Creating an agent takes only a few steps. Start with one of our templates and choose the default option.

![Create your agent from the signup screen](https://storage.kilobot.app/docs/docs-signup.png)

You should now have an agent ready to be trained.

## 2. Give your agent knowledge

The fastest way to give your agent knowledge is with text. Open **Knowledge Base**, choose **Q&A**, and add this example.

<DocExample title="Northstar Dental opening hours">

**Question:** What are your opening hours?

**Answer:** Northstar Dental is open Monday to Friday, 9:00 am to 6:00 pm, and Saturday, 9:00 am to 1:00 pm. It is closed on Sunday.

</DocExample>

![Add the opening-hours Q&A to the Knowledge Base](https://storage.kilobot.app/docs/docs-kb.png)

Wait until the source finishes processing before testing.

<div className="docs-image-compact">

![Source training in the Knowledge Base](https://storage.kilobot.app/docs/docs-training.jpeg)

</div>

Your agent is now ready to be tested with the knowledge.

## 3. Test your agent

Choose **Test agent** and ask one question the Knowledge Base can answer:

`Are you open on Saturday?`

<div className="docs-image-compact">

![Test the agent with the opening-hours question](https://storage.kilobot.app/docs/docs-testing.png)

</div>

Your agent is ready!

# Quick Start

<DocVerified date="2026-07-28" />

Build a working customer-facing agent, add one trusted answer, publish it, and confirm a real Website conversation in Inbox. The example uses **Northstar Dental** throughout and normally takes 10–15 minutes.

<DocPrerequisites>

- A KiloBot account and workspace
- Permission to create and publish an agent
- Access to edit and publish your business website
- A private browser window for the final visitor test

</DocPrerequisites>

## 1. Create your agent · About 2 minutes

<ol className="steps">
  <li>Open the workspace and choose <strong>Create agent</strong>.</li>
  <li>Select a starter template or start blank.</li>
  <li>Name the agent <strong>Northstar Booking Assistant</strong>.</li>
  <li>Complete creation to open the agent dashboard.</li>
</ol>

## 2. Add one trusted answer · About 2 minutes

Open **Knowledge Base**, select **Q&A**, and add this approved answer.

<DocExample title="Northstar Dental opening hours">

**Question:** What are your opening hours?

**Answer:** Northstar Dental is open Monday to Friday, 9:00 am to 6:00 pm, and Saturday, 9:00 am to 1:00 pm. It is closed on Sunday.

</DocExample>

Wait until the source finishes processing before testing.

## 3. Review the agent · About 2 minutes

Open **Agent Setup**. Confirm the prompt identifies the business, instructs the agent to use trusted knowledge, avoids inventing missing facts, and escalates requests that need a person. Review the model and style settings without adding business facts to the prompt.

## 4. Test before publishing · About 3 minutes

Choose **Test agent** and send:

1. `Are you open on Saturday?`
2. `Can I visit this weekend?`
3. `Do you offer emergency root canals?`

The first two should use the Q&A. The third should not invent an unsupported service.

- Any required escalation behavior matches the system prompt.

## 5. Publish the agent · Less than 1 minute

Choose **Publish** in Agent Setup. Publish makes the current draft active for connected customer channels. If KiloBot warns about an unpublished draft, return to Agent Setup and publish before continuing.

## 6. Connect the Website widget · About 3 minutes

<ol className="steps">
  <li>Open <strong>Channels</strong>.</li>
  <li>On the Website card, choose <strong>Connect</strong>.</li>
  <li>Configure the customer-facing name and appearance.</li>
  <li>Copy the script snippet and add it to the website.</li>
  <li>Publish the website change.</li>
</ol>

## 7. Verify the visitor experience · About 2 minutes

<ol className="steps">
  <li>Open the published website in a private browser window.</li>
  <li>Open the widget and ask <strong>Are you open on Saturday?</strong></li>
  <li>Confirm the reply uses the approved opening hours.</li>
</ol>

## 8. Confirm the conversation in Inbox · About 1 minute

Open **Inbox** for Northstar Booking Assistant, select the new Website conversation, and send a teammate reply. Confirm the reply reaches the private-window visitor.

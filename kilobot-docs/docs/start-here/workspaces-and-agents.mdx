# Workspaces and agents

## Overview

A workspace holds your team and billing. Each agent is a separate customer experience inside that workspace. Use one workspace when the same organization shares billing and team access. Create separate agents when the customer experience, knowledge, channels, or workflow should differ.

## Create a workspace

During onboarding, enter the team name, industry, and company size. Workspace-level pages manage members, invitations, roles, plan usage, and settings.

## Create an agent

Choose **Create agent** from the workspace, pick a template or blank starting point, name the agent, and complete the creation flow. Each agent has its own **Knowledge Base**, **Workflow**, **Channels**, **Inbox**, **Bookings**, and **Analytics**.

## Switch between agents

In the agent header, select the current agent name to switch. KiloBot keeps the same area open where possible. Open the **Agents** workspace page for the complete list and workspace controls.

## Plan before adding agents

Give each agent one clear responsibility — for example one brand, market, or customer journey. Use roles and permissions for teammate access, not duplicate agents.

:::note
Plan limits determine how many agents, teammates, and channels the workspace can use. Review **Usage** before expanding a production setup.
:::

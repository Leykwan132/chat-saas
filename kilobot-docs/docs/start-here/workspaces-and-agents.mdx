# Workspaces and agents

<DocVerified date="2026-07-28" />

A workspace holds the organization, team, and plan. An agent is one customer-facing AI experience inside that workspace.

<DocOutcomes>

### By the end, you will

- Choose when to create a workspace, agent, or invitation
- Create and switch between agents
- Keep each agent’s settings and customer experience separate

</DocOutcomes>

## Choose the right structure

| Need | Create | Why |
| --- | --- | --- |
| The same organization shares team access and plan | One workspace | Keeps ownership and administration together |
| A brand, market, or journey needs different knowledge, channels, or behavior | Another agent | Keeps the customer experience separate |
| A teammate needs access to existing work | A team invitation | Avoids duplicating agents or sharing accounts |
| A legally or operationally separate organization needs isolation | Another workspace | Separates membership and organization controls |

<DocExample title="Northstar Dental">

Northstar uses one workspace. It creates a **Northstar Dental** agent for patient enquiries. If a second clinic needs different services, operating hours, channels, and staff, Northstar creates another agent in the same workspace.

</DocExample>

## Create and switch agents

Choose **Create agent**, select a template or blank starting point, name the agent, and complete setup. Each agent has its own Agent Setup, Knowledge Base, Channels, Conversations, Bookings, and Workflows.

Use the agent switcher in the dashboard header to move between agents. Confirm the selected agent before changing settings or answering a customer.

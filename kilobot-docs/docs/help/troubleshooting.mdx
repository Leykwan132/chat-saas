# Troubleshooting

<DocVerified date="2026-07-28" />

Match what you see to a symptom below. Check the selected workspace and agent first; many apparent problems are changes made in a different agent.

<DocOutcomes>

### By the end, you will

- Diagnose common agent, channel, booking, and Broadcast problems
- Check workspace, agent, permissions, and connection state
- Gather useful evidence when support is needed

</DocOutcomes>

## 1. The agent gives an incomplete or incorrect answer

1. Confirm the fact exists in the selected agent's **Knowledge Base**.
2. Remove or correct contradictory sources.
3. Check whether the **Agent Setup** prompt conflicts with the fact.
4. Ask the same question in **Test agent**.
5. If the request should trigger an action, inspect the Workflow condition instead of adding general knowledge.

## 2. A channel is not connected or customer messages are missing

1. Open **Channels** and check the card for the affected platform.
2. Complete any visible reconnect or provider action.
3. For a new WhatsApp connection, allow initial synchronization to finish.
4. Send a new customer-side message.
5. Clear Conversation filters and confirm the correct agent is selected.

## 3. The AI is not replying

1. Check whether a teammate has taken over the conversation.
2. Review **Agent Setup → Reply mode**.
3. Confirm the connected channel is healthy and the workspace has available credits.
4. Inspect Workflow branches that may route or stop the reply.
5. Test a new conversation after saving changes.

## 4. An image, audio message, or attachment is unavailable

1. Refresh the conversation and retry the attachment.
2. Confirm the original channel message is still available.
3. Check that the file is within the platform's supported type and size.
4. Record the message time, platform, and attachment type before contacting support.

Do not forward private media to support unless it is necessary and authorized.

## 5. No booking times are available

1. Confirm the **Service** is active.
2. Check duration, buffer, assignment strategy, and assigned teammate.
3. Review **Availability**, timezone, and date-specific hours.
4. Inspect Calendar conflicts across the full service duration.
5. Try a controlled date that should be open.

## 6. A WhatsApp template is not selectable

1. Open **Broadcast → Message templates**.
2. Check whether the template is **Submitting**, **In review**, **Failed**, or **Approved**.
3. Confirm it belongs to the connected WhatsApp channel and intended use case.
4. Correct and resubmit a failed template.

Only **Approved** templates appear in Broadcast, Reminder, Follow-up, and Workflow selectors.

## 7. A Broadcast, Reminder, or Follow-up did not send

1. Confirm the selected template is still **Approved**.
2. Review the automation or Broadcast **History** status and reason.
3. For Reminders, verify the appointment is included in the reminder settings.
4. For Follow-ups, check the audience, no-reply timing, and whether the customer already replied.
5. Confirm the WhatsApp channel is connected.

## 8. A page or action is missing

1. Confirm the correct workspace and agent are selected.
2. Ask a team administrator to verify membership and role permissions.
3. Confirm the feature is available for the active plan.
4. Refresh after a role or plan change.

A missing navigation item or disabled action may be intentional when access is not granted.

## 9. A teammate cannot accept an invitation

1. Confirm the invitation was sent to the exact email they use to sign in.
2. Check whether the invitation is still pending.
3. Revoke duplicate or incorrect invitations.
4. Send one new invitation to the correct account.
5. After acceptance, verify the teammate appears as an active member.

## 10. Changes disappeared or never became active

1. Return to the edited page and look for **Save**, **Publish**, or **Confirm**.
2. Check Agent Setup, Workflows, Services, Availability, and template selection dialogs for drafts.
3. Save the change, reload the page, and verify the persisted value.
4. Re-run the related test before using the change with customers.

## If the issue remains

Collect the workspace and agent name, affected screen, approximate time with timezone, expected result, actual result, and reproduction steps. Add a screenshot or short recording with sensitive information hidden, then [contact support](/help/contact-support).

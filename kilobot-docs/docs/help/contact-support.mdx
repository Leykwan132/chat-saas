# Contact support

Use support after [Troubleshooting](/help/troubleshooting) does not unblock you. Prefer the bug form for a reproducible product issue, WhatsApp for account or setup help, and email for a detailed written trail.

## Choose a support route

| Need | Route |
| --- | --- |
| Reproducible product issue | <Link to="https://forms.gle/Hoo56T7Qj3yEBEeZ9">Bug report form</Link> |
| Account, setup, or operational help | <Link to="https://wa.me/60129499394">KiloBot support on WhatsApp</Link> |
| Detailed request with several steps | [support@kilobot.app](mailto:support@kilobot.app) |
| Sales or demo request | [KiloBot contact page](https://kilobot.app/contact) |

## Include useful evidence

- Workspace and agent name
- Page or feature
- Approximate date and time with timezone
- Steps that reproduce the problem
- Expected and actual result
- Browser and device
- Screenshot or short recording with sensitive data hidden
- Whether the problem affects one teammate, one channel, or the whole workspace

<DocExample title="Clear support report">

**Agent:** Northstar Dental

**Page:** Workflows → Reminders

**Time:** 28 July 2026, 3:15 PM MYT

**Expected:** A controlled test booking schedules a 24-hour reminder.

**Actual:** No History row appears.

**Tried:** Confirmed the template is Approved, scope is Future only, and the booking was created after activation.

</DocExample>

<DocSuccess>

- Support can identify the affected workspace, agent, and time
- The report contains reproducible steps and a clear expected result
- Any attachment hides unrelated customer or account information

</DocSuccess>

:::warning
Never send passwords, API keys, access tokens, complete payment details, or private customer exports through the form, WhatsApp, or email.
:::

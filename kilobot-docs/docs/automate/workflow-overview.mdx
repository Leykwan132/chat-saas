# Workflow overview

<DocVerified date="2026-07-28" />

Workflows give the agent an explicit operating path. Conditions describe when an action applies; actions define what KiloBot should do.

<DocOutcomes>

### By the end, you will

- Choose the correct Workflow view
- Understand how conditions trigger actions
- Decide when to use Reminders or Follow-ups

</DocOutcomes>

<DocPrerequisites>

- Agent-management permission
- Published business rules and customer-safe content
- Active Services and Availability before adding Book appointment

</DocPrerequisites>

## Choose the right view

| View | Trigger | Use it for |
| --- | --- | --- |
| Message handling | Current inbound message | Send content, book, escalate, or close |
| Reminders | Booked appointment time | Send an approved WhatsApp message before an appointment |
| Follow-ups | Customer silence | Re-engage an eligible customer after no reply |

Configure Reminder and Follow-up details under [Outreach](/automate/reminders).

## Understand the graph

**Message enters** is the start. Each connection can contain a condition with a short Name for the canvas and detailed matching guidance for the AI. The connected node performs the selected action.

Keep conditions precise and non-overlapping. Put exact customer-facing copy or uploaded media in the action rather than hiding it inside the condition.

## Work safely with drafts

- Applying a template changes the draft only.
- **Save** makes the current graph active.
- **Discard changes** returns to the last saved graph.
- **Arrange** improves layout without changing intent.
- Test positive matches and near-misses before relying on a branch.

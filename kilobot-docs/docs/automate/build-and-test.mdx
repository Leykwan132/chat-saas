# Build and test a Workflow

<DocVerified date="2026-07-28" />

This example sends Northstar Dental’s approved brochure when a customer asks for service information without treating a request for medical suitability as the same intent.

### By the end, you will

- Write a precise customer-intent condition
- Choose safe actions for the matched request
- Test matches and near misses before publishing

<DocPrerequisites>

- Agent-management permission
- The approved brochure file
- A published agent configuration

</DocPrerequisites>

## Write a precise condition

<DocExample title="Weak condition">

**Name:** Services

**Detail:** When they ask about services.

This can overlap with booking, pricing, clinical suitability, and support requests.

</DocExample>

<DocExample title="Strong condition">

**Name:** Product brochure

**Detail:** Match when the customer asks for the clinic brochure, a general treatment overview, or a document describing available services. Do not match questions asking whether a treatment is medically suitable for a specific person.

</DocExample>

## Build the branch

<ol className="steps">
  <li>Open <strong>Workflow → Message handling</strong>.</li>
  <li>Use the connection control beside <strong>Message enters</strong>.</li>
  <li>Add <strong>Send Files</strong> and select the new node.</li>
  <li>Enable the condition and enter the strong Name and Detail.</li>
  <li>Upload the approved brochure to the action.</li>
  <li>Save the Workflow.</li>
</ol>

## Choose an action

| Action | Example | Boundary |
| --- | --- | --- |
| Send message | Share exact preparation steps | Keep customer-facing copy in the action |
| Send Photo/Video | Send a clinic tour | Upload only approved media |
| Send Files | Send the brochure | Do not disclose internal filenames in replies |
| Book appointment | Start Northstar Consultation | Requires active Service and Availability |
| Human escalation | Hand off a complaint | AI pauses while a teammate owns the request |
| Close conversation | End a clearly completed thread | Keep the condition narrow and terminal |

## Test matches and near-misses

Use Test agent:

- **Match:** `Can you send me your treatment brochure?`
- **Paraphrase:** `I need a document explaining your services.`
- **Near-miss:** `Is this treatment safe for my condition?`
- **Other branch:** `I want to book a consultation.`

The first two should send the file. The near-miss must not. Booking should follow only the booking branch.

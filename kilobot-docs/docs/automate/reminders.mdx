# Reminders

<DocVerified date="2026-07-28" />

Reminders help you send appointment-time WhatsApp messages. Use them for appointment timing; use **Follow-ups** when the trigger is a customer who has not replied. Create and approve the template for closed-window sends under [Message templates](/engage/message-templates).

<DocOutcomes>

### By the end, you will

- Choose which appointments should receive reminders
- Configure approved messages and send timing
- See scheduled and completed sends in History

</DocOutcomes>

## Smart follow-up and reminder

Use the Meta conversation window to choose the message type before a reminder or follow-up is sent. The window starts when the customer sends a message and stays open for 24 hours.

| Conversation window | Message path | Pricing impact |
| --- | --- | --- |
| **Open** | Send a normal message | Avoids an unnecessary template charge |
| **Closed** | Send an approved WhatsApp Message Template | Meta's current template pricing applies |

This check lets you use a normal message for both smart reminders and smart follow-ups when the customer is still within the window. Meta charges are separate from KiloBot credits. See the [official WhatsApp pricing](https://whatsappbusiness.com/products/platform-pricing/) for current rates and treat any in-app estimate as an estimate.

:::important
Meta bills these message charges directly. Set up a valid payment method in your Meta Business account before activating Reminders. KiloBot is not where you add that card or top up Meta message credit.
:::

## Choose the activation scope

| Scope | Includes | Best for |
| --- | --- | --- |
| **Future only** | Eligible appointments created after activation | A clean, low-risk launch |
| **Current & future** | Remaining eligible sends for current upcoming appointments and new appointments | Applying the automation to an already-reviewed calendar |

The scope controls which appointments enter scheduling. It does not modify the appointments.

## Configure and activate

<ol className="steps">
  <li>Open <strong>Workflows → Reminders</strong>.</li>
  <li>Choose the activation scope.</li>
  <li>Choose how many reminders to send and when each should be sent.</li>
  <li>Select an approved WhatsApp template and choose <strong>Confirm</strong>.</li>
  <li>Review the Summary, then turn Reminders on.</li>
</ol>

## Monitor History

Open **History** from the Reminder Summary. Review the customer, template, scheduled time, sent time, status, and estimated Meta charge. Statuses include scheduled, sent, failed, skipped, and cancelled.

KiloBot shows estimates only where the template category has a known rate; unknown categories are excluded instead of guessed.

# Send messages and assets

<DocVerified date="2026-07-30" />

Use a Workflow when a customer request should send approved content instead of relying on the agent to compose a new response.

<DocOutcomes>

### By the end, you will

- Send an exact message when a customer request matches
- Deliver approved photos, videos, and files
- Keep near-miss requests on their intended paths

</DocOutcomes>

## 1. Create the send message

| Action | Use it for | Example |
| --- | --- | --- |
| **Send message** | Exact customer-facing text | Preparation instructions |
| **Send Photo/Video** | Approved visual media | A clinic tour |
| **Send Files** | Documents customers can open or download | A treatment brochure |

Keep the customer-facing content in the action. Use the condition only to explain when that action should run.

## 2. Describe the condition

Write a short Name that is easy to scan on the canvas, followed by a precise Detail that separates the request from similar intents.

<DocExample title="Northstar Dental brochure">

**Name:** Treatment brochure

**Detail:** Match when the customer asks for the clinic brochure, a general treatment overview, or a document describing available services. Do not match questions about pricing, booking, or whether a treatment is suitable for a specific person.

</DocExample>

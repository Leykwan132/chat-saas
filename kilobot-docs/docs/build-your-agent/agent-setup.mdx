# Agent Setup

<DocVerified date="2026-07-28" />

Agent Setup defines who the agent is, how it communicates, and when it should involve a person. Keep business facts in [Knowledge Base](/build-your-agent/knowledge-base) and use [Workflows](/automate/send-messages-and-assets) for requests that must perform an action.

<DocOutcomes>

### By the end, you will

- Decide where instructions, facts, and actions belong
- Write clear behavior, tone, boundaries, and escalation rules
- Review the agent behavior before using it

</DocOutcomes>

## Best practice

Keep Agent Setup focused on behavior: define the role, tone, boundaries, and escalation rules. Put durable business facts in the Knowledge Base and actions in Workflows so each change is easier to review and maintain.

## Decide where information belongs

| Put it in | Use it for | Example |
| --- | --- | --- |
| Agent Setup | Role, goals, tone, boundaries, escalation | “Never diagnose a medical condition.” |
| Knowledge Base | Durable facts the agent may answer from | Opening hours, pricing, policies |
| Workflow | A defined condition that performs an action | Send a brochure or book an appointment |

## Write the system prompt

A useful prompt identifies the agent, audience, goals, conversation behavior, knowledge limits, and handoff boundary.

## Models

Choose a model available to your workspace plan. Compare the available options before you decide:

| Model | Advantage | Disadvantage |
| --- | --- | --- |
| Ilmu Mini V3.3 | Strong for Malay/Bahasa Melayu and concise everyday support conversations. | Less suited to long, highly technical, or complex multi-step reasoning. |
| DeepSeek V4 Flash | Strong structured reasoning, technical explanations, and multilingual conversations, including Chinese. | Can be more verbose and may need tighter style instructions. |
| OpenAI GPT-OSS 120B | Strong general-purpose writing, nuanced instructions, and flexible conversation style. | May use more credits; always ground business answers in the Knowledge Base. |

## Triggers

Choose whether the agent should reply to every incoming message automatically or only after a teammate assigns the conversation.

| Reply mode | Use it when |
| --- | --- |
| Automatically | The agent should reply to every incoming message. |
| Manual | A teammate should assign the conversation before the agent replies. |

:::tip
If you want to send an item reliably, use a [Workflow](/automate/send-messages-and-assets). Workflows send approved messages and assets when a specific request matches.
:::

## Common problems

- **The answer is wrong:** correct conflicting Knowledge Base sources before expanding the prompt.
- **An action does not run:** check the Workflow condition and near-miss tests.
- **AI does not reply:** check conversation AI state, Reply mode, credits, permissions, and channel connection.
- **A change is absent:** confirm the latest changes were saved.

# Knowledge Base

<DocVerified date="2026-07-28" />

Knowledge Base is the selected agent’s trusted source for business facts. Sources are agent-specific: confirm the correct agent before adding, replacing, or deleting information.

<DocOutcomes>

### By the end, you will

- Choose the right source type
- Add, replace, and remove trusted information
- Ground answers in approved facts

</DocOutcomes>

## Supported sources

| Source | Best for | Avoid when |
| --- | --- | --- |
| Web | Current public pages with related content | The site contains conflicting or private material |
| Files | Approved documents supported by the upload control | The document changes frequently |
| Text | A focused fact or policy that has no source page | The note would duplicate another source |
| Q&A | A direct question with a concise approved answer | Many questions need the same long document |

The upload control and **Storage limit** panel are authoritative for currently supported file formats, per-source limits, and plan allowance.

## Add a source

<ol className="steps">

  <li>Select the source type.</li>
  <li>Add only the focused material the agent should use.</li>

## Keep sources reliable

- Prefer one authoritative source for pricing, policies, hours, and service details.
- Remove obsolete and duplicate sources.
- When replacing information, wait for the new source to finish processing before deleting the old source.
- If two sources disagree, correct the source set instead of asking the prompt to choose.
- Deleting a source removes it from future grounding; test important answers again afterward.

## Monitor storage

Open **Storage limit** to review usage by source type and the selected agent’s allowance. Remove obsolete large files and duplicate material before adding another copy.

## Best practice

### Convert PDFs to text

When a PDF contains important business facts, convert it to clean text first and add that text as a source. Text is easier to review and often gives the agent more reliable grounding than extracting directly from a PDF.

:::warning
Extracting information from an image or PDF is not 100% accurate. Scans, tables, columns, and formatting can be missed or misread, so review converted text and confirm important answers before relying on it.
:::

## Common problems

- **Processing does not finish:** retry the supported source or contact support with the source type and approximate time.
- **The answer is incomplete:** make the source focused and explicit.
- **The answer contradicts policy:** locate and remove the stale source.
- **An action should happen:** use a [Workflow](/automate/send-messages-and-assets) instead of adding more general knowledge.

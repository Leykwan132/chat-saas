# Calendar

<DocVerified date="2026-07-28" />

Calendar is the shared operational view for AI-created and teammate-created bookings. Past events are visually muted after their end time; current and future events remain prominent.

<DocOutcomes>

### By the end, you will

- Create a customer booking manually
- Check availability and prevent scheduling conflicts
- Update appointment status and review booking history

</DocOutcomes>

## Create a booking manually

The Service duration provides the initial end time, but a valid custom interval can be selected. KiloBot checks availability before enabling creation and revalidates on submission.

<ol className="steps">
  <li>Open <strong>Calendar</strong> and choose the create action.</li>
  <li>Find and select the Contact.</li>
  <li>Select <strong>Northstar Consultation</strong>.</li>
  <li>Choose the date, start time, and end time.</li>
  <li>Complete required fields and optional remarks.</li>
  <li>Create the booking after the availability check succeeds.</li>
</ol>

## Use accurate statuses

| Status | Use it when |
| --- | --- |
| Scheduled | The upcoming appointment is confirmed |
| Completed | The appointment took place |
| Cancelled | The appointment will not proceed |
| No-show | The customer did not attend |

Status affects customer history, reporting, and automation decisions. Review [Reminders](/automate/reminders) before changing many appointments.

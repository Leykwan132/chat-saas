# Calendar

Calendar is the operational view of appointments created by the AI agent or by a teammate.

## Navigate the Calendar

Past events are visually muted after their end time. Select an appointment to review its date, customer detail, Service fields, and team assignment. Booking information is also available from the customer's conversation in **Inbox**.

<ol className="steps">
  <li>Open <strong>Calendar</strong> from the agent sidebar.</li>
  <li>Use the sidebar to choose the view and teammate context.</li>
  <li>Review events in the main calendar or the <strong>Today</strong> list for current and upcoming work.</li>
</ol>

## Create a booking manually

Staff-created bookings use the same Service and schedule checks as AI bookings. The Service duration provides the initial end time, but you can use a valid custom interval. KiloBot checks the Service and schedule before allowing creation and revalidates when you submit. If the slot conflicts or required context is incomplete, creation is blocked.

<ol className="steps">
  <li>Choose the create action.</li>
  <li>Find the <strong>Contact</strong>.</li>
  <li>Select a <strong>Service</strong>, date, start time, and end time.</li>
  <li>Complete the required booking fields.</li>
  <li>Submit the booking.</li>
</ol>

## Update appointment status

Status affects the customer record, history, and reporting. Open the event details and set the status that reflects the real outcome:

- **Scheduled** for an upcoming confirmed appointment
- **Completed** after the appointment takes place
- **Cancelled** when it will not proceed
- **No-show** when the customer did not attend

## Edit or cancel

<ol className="steps">
  <li>Open the event details.</li>
  <li>Edit permitted fields or cancel the appointment.</li>
</ol>

Changes made by a teammate and by the AI are recorded in the conversation's **Action History** where applicable.

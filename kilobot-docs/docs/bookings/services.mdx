# Services

<DocVerified date="2026-07-28" />

A Service combines customer-facing details, timing, booking fields, sales style, and teammate assignment. Availability and Calendar determine whether the assigned teammate can actually accept a requested time.

### By the end, you will

- Create a customer-facing Service
- Configure timing, booking fields, and assignment
- Test that customers can book an eligible teammate

<DocPrerequisites>

- Booking-automation management permission
- At least one eligible workspace teammate
- Approved booking questions and timing rules

</DocPrerequisites>

## Create a Service

<DocExample title="Northstar Consultation">

- **Duration:** 30 minutes
- **Buffer:** 15 minutes
- **Required fields:** Customer name, phone number, reason for visit
- **Assignment:** Conversation owner first

</DocExample>

<ol className="steps">
  <li>Open <strong>Services</strong> and choose <strong>Add a service</strong>.</li>
  <li>Enter the name, customer-facing description, and active state.</li>
  <li>Set duration, buffer, timezone, and any preferred times.</li>
  <li>Choose only the booking fields the team needs.</li>
  <li>Choose the sales style and assignment strategy.</li>
  <li>Save the Service.</li>
</ol>

Keep conversational data collection short. Default booking context includes date, time, customer name, and phone number; add text, number, select, yes/no, date, time, or phone fields only when the team will use them.

## Choose an assignment strategy

| Strategy | Choose it when |
| --- | --- |
| Conversation owner first | The existing relationship should take priority |
| Balanced | Work should favor teammates with less assigned load |
| Round robin | Eligible teammates should rotate predictably |
| Specific teammate | One person exclusively owns the Service |

Availability remains required for every strategy.

## Activate and connect it

<ol className="steps">
  <li>Confirm the Service is active.</li>
  <li>Set [Availability](/bookings/availability) for every eligible teammate.</li>
  <li>Open a <strong>Book appointment</strong> Workflow action and select the Service.</li>
  <li>Run a complete booking in Test agent.</li>
</ol>

Editing a Service changes future booking evaluation. Deactivation prevents it from producing new bookable options; existing appointments remain operational records and should be reviewed in Calendar.

# Availability

<DocVerified date="2026-07-28" />

Availability tells KiloBot when a teammate may receive a booking. A slot must fit weekly hours, timezone, Service duration and buffer, Calendar conflicts, and assignment eligibility.

### By the end, you will

- Set weekly hours and the correct timezone
- Account for Service duration, buffers, and Calendar conflicts
- Diagnose why a booking slot is unavailable

<DocPrerequisites>

- An active Service
- An eligible teammate
- Availability management permission, or access to edit your own schedule

</DocPrerequisites>

## Set weekly hours

<ol className="steps">
  <li>Open <strong>Availability</strong> and select the teammate.</li>
  <li>Enable the days the teammate works.</li>
  <li>Set a start and end time for each enabled day.</li>
  <li>Choose the timezone that matches those hours.</li>
  <li>Save and review every day.</li>
</ol>

**Available 24/7** sets all seven days to `00:00–24:00`. Turning it off resets all days to `09:00–17:00`; it does not restore the earlier custom schedule.

## Understand slot evaluation

For a 30-minute Northstar Consultation with a 15-minute buffer, KiloBot needs a continuous valid interval that includes both. The assigned teammate must be eligible and free in Calendar in the same schedule timezone.

## Troubleshoot a missing slot

Check in this order:

1. **Service:** Is Northstar Consultation active and selected by the Workflow?
2. **Eligibility:** Can the intended teammate receive this Service?
3. **Timezone:** Are the displayed hours interpreted in the intended zone?
4. **Weekly hours:** Does the appointment fit entirely inside an enabled period?
5. **Duration and buffer:** Is there enough continuous time?
6. **Calendar:** Does another event overlap?
7. **Assignment:** Can another eligible teammate offer the slot?

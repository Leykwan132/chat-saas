## July 2026

<article data-product="Avatar">

<time dateTime="2026-07-23">2026-07-23</time>

### Avatar — Voice avatar preview

#### New features

- Added a feature-flagged Avatar preview for selected workspaces, with guided setup for choosing an avatar, language, and voice, plus inline voice previews.
- Added voice-only conversations with controls to start, mute, unmute, and end a session.
- Added website embedding with ready-to-copy HTML or React snippets that use the same configured Avatar experience.
- Connected Avatar conversations to Inbox so teams can review and continue the customer relationship.

#### Improvements

- Added a responsive video stage that keeps the configured Avatar preview and session controls consistent across the dashboard and embedded experience.

</article>

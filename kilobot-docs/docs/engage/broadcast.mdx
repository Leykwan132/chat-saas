# Broadcast <span className="docs-required-tag">Payment method required</span>

<DocVerified date="2026-07-28" />

Broadcast sends one approved WhatsApp Message Template to a selected group of Contacts. Use it for a planned campaign or announcement, not one-to-one support.

<DocOutcomes>

### By the end, you will

- Choose an approved template and audience
- Review message variables, recipients, and estimated charges
- Send safely and inspect delivery history

</DocOutcomes>

## Smart sending and pricing

Broadcasts are for audience-level, business-initiated messages. Before sending, check the Meta conversation window for each recipient. The window starts when the customer sends a message and stays open for 24 hours.

| Conversation window | Best message path | Pricing impact |
| --- | --- | --- |
| **Open** | Send a normal one-to-one message or workflow instead of a Broadcast | Avoids an unnecessary template charge |
| **Closed** | Send the approved WhatsApp Message Template through Broadcast | Meta's current template pricing applies |

Use the open-window path when a personal reply is enough; keep Broadcast for a true audience send. Meta charges are separate from KiloBot credits. See the [official WhatsApp pricing](https://whatsappbusiness.com/products/platform-pricing/) for current rates and treat any in-app estimate as an estimate.

## Create a Broadcast

<ol className="steps">
  <li>Open <strong>Broadcast → Create a broadcast</strong> and choose <strong>New Broadcast</strong>.</li>
  <li>Select the WhatsApp channel and an approved template.</li>
  <li>Define the audience using Contact criteria.</li>
  <li>Review the recipient count and preview resolved parameters.</li>
  <li>Review the estimated Meta charge.</li>
  <li>Send now or choose the available schedule option.</li>
  <li>Confirm only after checking the audience, template, and timing.</li>
</ol>

<DocExample title="Safe first campaign">

Create a small internal test audience, send the complete campaign to that group, and confirm the rendered variables and reply path before selecting production Contacts.

</DocExample>

## Pricing

The displayed MYR amount is an estimate based on known template pricing; final charges come from Meta. Meta bills WhatsApp message charges directly to your Meta Business account. Set up a payment method there before activating Broadcast. See [Add payment](/channels/whatsapp#add-payment) for the required setup. KiloBot credits are separate, and KiloBot is not where you add a card or top up Meta message credit. See the [official WhatsApp pricing](https://whatsappbusiness.com/products/platform-pricing/) for current rates. Unknown categories are excluded instead of guessed.

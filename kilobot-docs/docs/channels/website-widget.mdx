# Website widget

<DocVerified date="2026-07-28" />

The Website widget is the fastest way to make a published agent available to visitors.

<DocPrerequisites>

- A published agent
- Channel-management permission
- Access to edit and publish the website

</DocPrerequisites>

## Create and install the widget

<ol className="steps">
  <li>Open <strong>Channels</strong> and choose <strong>Connect</strong> on Website.</li>
  <li>Configure the customer-facing name, appearance, launcher, and greeting.</li>
  <li>Copy the complete script snippet.</li>
  <li>Add it once to the website layout so it loads on the intended pages.</li>
  <li>Publish the website change.</li>
</ol>

## Common problems

- **Widget is absent:** confirm the complete snippet is present in the published build.
- **Widget appears twice:** remove duplicate installations from page and global layouts.
- **Old settings remain:** publish the latest site version and test without cached visitor state.
- **Message reaches the wrong agent:** replace the snippet with the one copied from the intended agent.
- **Security policy blocks the script:** allow the KiloBot script and network origins in the website policy.

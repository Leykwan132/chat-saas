# Website widget

<DocVerified date="2026-07-28" />

The Website widget is the fastest way to make a published agent available to visitors. Setup is straightforward: configure it, copy one snippet, and publish it on your site.

<DocOutcomes>

### By the end, you will

- Configure the Website widget
- Install it on your website
- Verify that visitor messages reach Inbox

</DocOutcomes>

## Create and install the widget

<ol className="steps">
  <li>Open <strong>Channels</strong> and choose <strong>Connect</strong> on Website.</li>
  <li>Configure the customer-facing name, appearance, launcher, and greeting, then copy the script snippet.</li>
  <li>Add the snippet once to the website layout and publish the change.</li>
</ol>

Open the published page in a private window, start a conversation, and confirm the message appears in the correct Inbox. Send a teammate reply and verify it in the widget.

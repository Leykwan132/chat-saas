# Messenger

<DocVerified date="2026-07-28" />

Connect a Facebook Page so supported Messenger conversations enter the selected agent’s Inbox. Setup is straightforward: sign in, choose the Page, and grant access.

<DocOutcomes>

### By the end, you will

- Connect the correct Facebook Page
- See a Page message reach Inbox
- Send a teammate reply from KiloBot

</DocOutcomes>

## Conversation window

- **When it opens:** A customer messages your Facebook Page.
- **While it is open:** KiloBot can reply.
- **After it closes:** Messenger rules may limit business-initiated messages or require the customer to message again.

## Connect

<ol className="steps">
  <li>Open <strong>Channels</strong> and choose <strong>Connect</strong> on Messenger.</li>
  <li>Sign in to Meta, select the intended Facebook Page, and grant messaging access.</li>
  <li>Return to KiloBot, then send a new Page message and reply from Inbox.</li>
</ol>

# Messenger

<DocVerified date="2026-07-28" />

Connect a Facebook Page so supported Messenger conversations enter the selected agent’s Inbox.

<DocOutcomes>

### By the end, you will

- Connect the correct Facebook Page
- Verify a Page message reaches Inbox
- Send a teammate reply from KiloBot

</DocOutcomes>

<DocPrerequisites>

- Administrator access to the intended Facebook Page and business
- Permission to grant Page messaging access
- KiloBot channel-management permission

</DocPrerequisites>

## Connect and verify

<ol className="steps">
  <li>Open <strong>Channels</strong> and choose <strong>Connect</strong> on Messenger.</li>
  <li>Sign in to Meta and select the intended Facebook Page.</li>
  <li>Grant the requested messaging access and return to KiloBot.</li>
  <li>Send a new Page message from a separate Facebook account.</li>
  <li>Confirm the conversation in Inbox and send a teammate reply.</li>
</ol>
